```
│                                               │                              │
│ C  Farbpsychologie                            │                              │
│    Assoziationen, Kontext, Kultur, Forschung  │                              │
│    ┌ Tradition und Forschung ───────────────┐ │                              │
│    │ Tradition        │ Forschung           │ │                              │
│    └────────────────────────────────────────┘ │                              │
│ D  Spirituelle Bedeutung  → Link Chakren      │                              │
│ E  Farbtherapeutische Anwendung               │                              │
│ F  Kultur und Geschichte                      │                              │
│ G  Übung (Start/Pause/Ende, freiwillig)       │                              │
│ H  Quellen (Liste mit Datum/Typ) + 3 Karten   │                              │
└───────────────────────────────────────────────┴──────────────────────────────┘
```

Zustände:

- **Ohne Inhalt in einem Abschnitt:** Abschnitt entfällt vollständig (keine
  leere H2).
- **Fehlende Quelle:** Quellenzeile „Quelle in Prüfung“ ist unzulässig; dann
  entfällt die Aussage.
- **Fokus:** Sprungmarken setzen Fokus auf die Zielüberschrift
  (`tabindex="-1"`, sichtbarer Fokus).

## 6. Interaktionszustände (für alle Seitentypen)

| Element | Ruhe | Hover | Fokus | Auswahl | Deaktiviert |
| --- | --- | --- | --- | --- | --- |
| Register-Zeile | Fläche transparent | `--color-bg-card` | 2 px Sand, 4 px Offset | – | – |
| Farbkarte (verlinkt) | Rahmen `--color-border` | Rahmen `--color-line-strong`, Titel unterstrichen | 2 px Sand | – | – |
| Chakra-Knoten | 1 px `--color-line-strong` | Rahmen Sand | 2 px Sand außen | 2 px Sand + Innenkante | – |
| Button primär | Sandfläche, dunkle Schrift | Sand-Hover | 2 px Sand, 4 px Offset | – | 45 % Deckkraft, `cursor:not-allowed` |
| Slider (FW-07) | 2 px Spur `--color-line-strong`, Griff Sand | – | 2 px Sand | – | – |

Kein Zustand darf ausschließlich über Farbe unterscheidbar sein: Auswahl
zusätzlich über Rahmenbreite/`aria-pressed`, aktive Navigation zusätzlich über
Unterlinie und `aria-current`.
