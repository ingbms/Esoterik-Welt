# Esoterik-Welt CSS

- `design-system.css`: Tokens, Typografie, Spacing, Komponenten (Button, Card, Modal, Tooltip, Toggle); `[data-theme="light"]` ist eine reservierte, nicht erreichbare Token-Skizze (siehe `docs/design-tokens.md`)
- `main.css`: Layout-spezifisch

Verwendung: `<link rel="stylesheet" href="css/design-system.css">`
